# Galeria-de-fotos

Um projeto para realizar login com JavaScript por meio da API JSONPlaceHolder e interação com uma galeria de fotos.

# Passos para executar
O presente projeto não apresenta dependências que necessitam ser instaladas, podendo ser rodado normalmente a partir do repositório clonado.

Todos os testes feitosforam bem sucedidos, uma vez que o login foi implementado e está funcionando como esperado, assim como a parte da ampliação das imagens e a função de logout.
